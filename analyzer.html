一、仪器功能

检偏器（Analyzer, A）用于检验光的偏振态。 在结构上与起偏器完全相同，都是偏振片，但作用不同： 起偏器用于"产生"线偏振光，检偏器用于"分析"光的偏振状态。

旋转检偏器的透振方向，根据透射光强的变化规律即可判断入射光的偏振态：

· 线偏振光：旋转 360° 内出现 两次完全消光；

· 圆偏振光或自然光：旋转时光强保持不变；

· 椭圆偏振光或部分偏振光：旋转时光强变化但无消光。

二、操作方法

· 验证马吕斯定律（无波片时）：

　1. 在 P 与接收器之间放入 A，旋转 A 找出最大读数 I₀，记为 A(0)；

　2. 每隔 10° 或 15° 记录一次透射光强 I，共取 36~24 个数据点；

　3. 以 α 为横坐标、I/I₀ 为纵坐标，绘制曲线应与 cos²α 吻合；

　4. 以 ln(cos α) 为自变量、ln I 为因变量进行线性拟合， 求出 I = I₀·cosnα 中的 n（理想偏振片 n = 1）和相关系数 r。

· 消光法判别偏振态：

　1. 不放波片，旋转 A，若出现两次消光 → 入射光为线偏振光；

　2. 加入 1/4 波片再观察：

　　- 若再次出现消光 → 入射光为圆或椭圆偏振光；

　　- 若仍不消光 → 入射光为部分偏振光；

　- 强度始终不变 → 入射光为自然光。

三、物理原理

检偏器的核心是马吕斯定律（Malus's Law）：

设入射的线偏振光振动方向与检偏器透振方向的夹角为 α， 透过检偏器的光强为 I = I₀·cos²α。

· 当 α = 0°：I = I₀（最大）；

· 当 α = 90°：I = 0（消光）；

· 当 α 在 0°~360° 范围内：I 呈周期性变化，周期 180°。

对于椭圆偏振光（经过波片后），需用推广公式： I = I₀[cos²ψ·cos²φ + sin²ψ·sin²φ]， 其中 φ = P − C，ψ = A − C。

四、实验关键点

1. 消光读数应缓慢：接近消光位置时光强变化极快，需要缓慢转动 A；

2. 零点定位：最大光强位置定为 A(0)，消光位置约在 A(0) + 90°；

3. 与 P 严格区分：本实验需要两套独立的偏振片（结构相同）， P 用于产生线偏振光，A 用于检验；

4. 数据采集间隔：测量马吕斯定律曲线时，每 10° 或 15° 取一个数据点， 共需 36 或 24 个数据点；

5. 消光比：理想偏振片的消光比 ≥ 100:1，实际使用中要选高消光比的偏振片以减小误差。
